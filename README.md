# RecSys Daily

RecSys Daily 是一个面向推荐系统研究与工程实践的中文日报，自动汇集 arXiv 论文与高质量工程博客，并提供中文摘要、结构化解读、归档、搜索和知识图谱。

RecSys Daily is a Chinese research digest for recommendation-systems papers and engineering blogs, with structured summaries, archives, search, and an interactive knowledge graph.
